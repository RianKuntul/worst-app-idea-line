A make.fun entry for "The Worst App Idea Ever Pitched": a tiny Node program
that writes one sentence pitching the worst, most useless app imaginable to
`entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/worst-app-idea-out node main.ts
```

This writes `/tmp/worst-app-idea-out/entry.txt` — one sentence, at most 240
characters including the trailing newline.
